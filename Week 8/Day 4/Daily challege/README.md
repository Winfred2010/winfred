# React Calculator Daily Challenge

A lightweight React calculator that adds two numbers and supports four operations.

## Features
- Enter two numbers in separate inputs
- Choose one of: addition, subtraction, multiplication, division
- Click a button to compute and display the result
- Validation for invalid input and division by zero

## Run locally
1. Install dependencies:
   ```bash
   npm install
   ```
2. Start the development server:
   ```bash
   npm run dev
   ```

## Files
- `App.jsx` — main calculator logic
- `index.jsx` — app entry point
- `styles.css` — styling
